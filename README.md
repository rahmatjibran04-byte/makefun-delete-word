## The word

**moist**

The most-hated word in the English language — hated purely for how it
sounds. Deleting it is a relief every reader feels the instant they read
it: no explanation, no caption, no defence needed. The humour comes
entirely from the word itself, and the gap it leaves is one nobody would
miss. It is fresh in this field and instantly understood.

## How it works

`main.py` writes the single word `moist` to `/output/entry.txt` — UTF-8,
5 characters, one word, no trailing newline, no network, no input.

```sh
python3 main.py
cat /output/entry.txt   # moist
```
